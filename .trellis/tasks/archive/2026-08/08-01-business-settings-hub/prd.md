# 业务域系统设置与客户管理聚合壳

## Goal

业务域端侧栏收拢配置类菜单：保留作业入口，配置进入「系统设置」「客户管理」二级中枢（方案 B），事项配置保持一级独立。

## Confirmed Decisions

| 项 | 结论 |
|:---|:---|
| 形态 | 全局侧栏 catalog 展开子菜单（非页内 Hub 二级栏） |
| 客户管理 | 一级入口；二级：客户列表、入域配置 |
| 组织成员 | **一级**入口；二级：员工管理、角色管理、入域管理 |
| 系统设置 | 一级入口；二级：通用设置 + 功能配置 + 安全与审计 |
| 事项配置 | 不进壳，保持一级 |
| 旧路径 | redirect 到新路径 |

## 侧栏一级结构（相关）

1. **组织成员**（一级）— 员工管理、角色管理、入域管理  
2. **系统设置**（一级）  
   - 通用设置（置顶）  
   - 功能配置 — 参数 / 屏蔽词 / 通知  
   - 安全与审计 — 操作 / 登录日志  

## Acceptance Criteria

- [ ] AC1：侧栏点击「客户管理」「系统设置」展开下方子菜单（非页内二级栏）  
- [ ] AC2：客户管理下含客户列表、入域配置  
- [ ] AC3：组织成员为一级菜单；系统设置下通用设置置顶，含功能配置 / 安全与审计分组  
- [ ] AC4：旧 `/domain/basic|members|…` redirect 可用  
- [ ] AC5：权限码不变；无菜单绑定则不可见  

## Out of Scope

- 事项配置壳改造、入域写增强、通知成品、平台端菜单
