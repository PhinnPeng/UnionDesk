# CustomerWeb 服务台 Context

客户自助服务门户（CustomerWeb V3 服务台）的领域语言。客户通过该门户提交/跟踪工单、发起咨询、接收通知并评价服务。

## Language

**工单（Ticket）**：
客户通过服务台提交的服务请求，由客服处理。正式工单必须有标题与描述，生成唯一工单号（如 UD-20260809-001）。
_Avoid_: 请求单、Case

**草稿（Draft）**：
客户在新建工单时未提交的临时内容（类型/标题/描述），后端持久化，每客户每业务域仅一份。不属于工单，无工单号，仅存在于「待提交」视图。
_Avoid_: 暂存、未完成工单

**生命周期桶（Lifecycle Bucket）**：
客户视角的工单分类维度，互斥不重叠：待提交（草稿）/ 进行中 / 待评价 / 已完成。与工单原始状态（open/processing/...）解耦，由映射函数聚合。
_Avoid_: 状态 Tab、筛选分组

**待评价（Pending Review）**：
已解决或已关闭但客户尚未提交满意度评价的工单；评价后自动落入「已完成」。
_Avoid_: 待满意、未评价

**客户侧删除（Customer-side Delete）**：
客户删除仅将工单从自己的列表隐藏（软删），客服端仍可见；不可恢复。
_Avoid_: 删除工单、彻底删除

**业务域（Business Domain）**：
客户可访问的服务组织空间（如某 SaaS 租户），工单/类型/草稿均归属业务域。
_Avoid_: 租户、项目

**工单类型（Ticket Type）**：
业务域内启用的工单分类（如技术/账户/账单），决定新建工单时可选类型与表单模板。
_Avoid_: 分类、表单模板
